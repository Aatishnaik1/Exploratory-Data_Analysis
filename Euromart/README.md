# 🛒 Euromart Sales Analysis Project

This project performs Exploratory Data Analysis (EDA) on the **Euromart Sales dataset** to understand customer purchasing patterns, product performance, revenue distribution, and overall business insights.  
The analysis helps identify top-selling products, profitable segments, and trends useful for improving sales strategy and customer targeting.

---

## 📌 Project Overview

The goal of this project is to analyze Euromart’s sales data and extract actionable insights.  
This includes:
- Understanding customer demographics  
- Identifying high revenue-generating products  
- Exploring city- and region-wise sales performance  
- Studying quantity, discount, profit, and loss patterns  
- Detecting outliers and trends  
- Providing data-driven recommendations  

---

## 🗂️ Dataset Information

The dataset includes the following typical features:
- Invoice ID  
- Branch / City / Region  
- Customer demographics  
- Product category and product line  
- Quantity  
- Unit price  
- Discount  
- Gross income / Profit  
- Payment method  
- Date and Time of purchase  

All data was cleaned, processed, and analyzed inside the notebook:

`Euromart_Sales.ipynb`

## 🧹 Data Cleaning & Preparation

Cleaning steps performed:
- Handled missing values  
- Removed duplicates  
- Converted columns to appropriate data types  
- Created new calculated fields (e.g., Total, Profit, Year, Month)  
- Standardized text data (categories & labels)

---

## 📊 Exploratory Data Analysis

Visualizations & analysis include:
- Sales by city and branch  
- Product line performance  
- Gender-based and age-based customer insights  
- Revenue and profit distribution  
- Payment method trends  
- Time-based (monthly/daily) sales analysis  
- Heatmaps for correlations  
- Outlier detection using boxplots  

---

## 📝 Key Insights

- Certain product lines contribute significantly higher revenue.  
- Cities/branches show different buying patterns and sales performance.  
- Payment methods and time-of-day preferences vary across customers.  
- Profitability varies across categories due to pricing and discount strategies.  
- Customer segments can be targeted based on purchasing frequency and total spend.
